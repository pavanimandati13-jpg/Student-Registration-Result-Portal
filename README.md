## 📌 Project Description

The **Student Registration & Result Portal** is a simple and interactive web application that allows students to enter their personal details, select a course, enter subject marks, and calculate their result automatically.

The application uses **JavaScript** to validate the entered information, calculate total marks and percentage, and display the **Pass/Fail** result dynamically.

---

## 🎯 Objectives

The main objectives of this project are:

* Enter student personal details.
* Select a course.
* Enter marks for different subjects.
* Calculate total marks using JavaScript.
* Calculate the percentage automatically.
* Display Pass/Fail status.
* Validate the entered information.
* Display student details and results dynamically.

## ⚙️ How It Works

1. The user enters the student's name, roll number, and email.
2. The user selects a course.
3. The user enters marks for four subjects.
4. JavaScript validates the entered information.
5. The total marks are calculated.
6. The percentage is calculated.
7. The result is determined as **PASS** or **FAIL**.
8. The student details and result are displayed dynamically.

### Result Calculation

```text
Total Marks = Sum of all subject marks

Percentage = Total Marks / Number of Subjects
```

The student is displayed as **PASS** when the required marks are achieved in all subjects; otherwise, the result is displayed as **FAIL**.
